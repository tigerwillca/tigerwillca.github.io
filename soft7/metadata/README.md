# Staged Tone trait

Files in this folder are **not** live metadata.

Do not upload them to OpenSea, IPFS, or the chain. Nothing here has been pushed.

`opensea-tone-attribute-patch.json` is the proposed addition for Soft7 77 (contract `0x5db625c49b2a9DD40464069fc16B9a2f3B11bF3d`, chain 4663). Each token gets one attribute:

`trait_type`: Tone  
`value`: `{hz} Hz · {batchName}`

Example: `256 Hz · Threshold` on piece 001.

The Hz values come from `../tones/tones.json`. Applying this means editing the pinned metadata later, on purpose, after William says so.
